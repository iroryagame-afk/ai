现在怎么做：把“猜底”改成四级仓位门

01 / ACTION

下列比例是“计划投入科创50资金”的比例，不是总资产比例。A股ETF同样需要把T日收盘信号与T+1成交分开；跳空高开时不追着完成目标仓位。

WAIT0%–10%

仍在1.76以下：等待为主。1.64–1.65是长期均线与60日低位共振区，但只作失效观察，不见价就抄底。

STARTER10%–20%

收盘放量收复1.76–1.77：建立试仓。次日若大幅高开，不追；等回踩不破再执行。

ADD25%–35%

收盘站稳1.83，且半导体ETF同步改善：确认反弹有扩散，可增加波段仓。

CORE40%–50%

连续站稳1.90–1.91，新股成交降温、ETF份额扩张且未来4–8周发行压力清晰：由波段仓转中期仓。

失效纪律：收盘有效跌破1.64–1.65，停止低吸并将战术仓降至0%–10%；反弹到1.90附近但量能衰减、半导体仍弱，则先兑现波段仓，而不是自动转成长持有。

为什么会“你涨我跌”：不是永久反向，而是五段传导

03 / TRANSMISSION
01发行与申购

机构与活跃资金腾挪现金，卖出既有科创权重或同类ETF。

02上市价格发现

新龙头首日成交巨大，交易注意力和风险预算集中。

03存量估值重排

资金比较新旧龙头的产业纯度、利润与市值，旧权重承压。

04指数纳入预期

市场提前交易被动买入与老成分被稀释，但时间受规则约束。

05长期业绩验收

若新龙头盈利兑现，指数质量上升；若仅靠高估值，抽水效应可能反复。

短期为什么偏负面

长鑫的高成交只是第一轮显性抽水。宇树发行、智谱150亿元拟募资与MiniMax后续申报可能分批占用机构风险预算；如果窗口相邻，科创50即使不跌，也可能表现为反弹高度受限和内部轮动加快。

长期为什么可能转正

GPU、存储、具身智能和基础模型逐步进入后，科创50从传统硬科技指数升级为中国AI全栈旗舰指数。单一样本10%权重上限削弱个股绑架，但前提是盈利兑现与ETF增量资金能覆盖新增供给。

上市不等于立刻进入科创50：真正要盯的是纳入规则

05 / INDEX RULES

可能快速纳入的条件

  • 上市以来日均总市值进入科创板前5，且上市超过3个月。
  • 日均总市值进入前3、上市超过1个月，并经专家委员会讨论通过。
  • 流动性筛选合格，且不存在重大违法、经营问题或异常表现。

不会自动发生的事情

  • 上市首日暴涨，不代表次日就进入科创50。
  • 注册获批不代表发行价、上市日与纳入权重已经确定。
  • DeepSeek产品上线或模型升级，不等于公司启动IPO。
  • 赴港上市不会自动成为科创50成分。

07 / MONITOR

加仓确认

  • 588000收盘依次站上1.76、1.83和1.90。
  • 成交量高于20日均量，但不是冲高回落巨量。
  • 半导体ETF同步收复中期均线，行情不再只靠新股。
  • ETF份额与价格同涨，显示增量资金进入。

事件跟踪

  • 长鑫日成交额、换手率及科创50纳入公告。
  • 宇树询价、申购、上市日期和首周成交。
  • 智谱A股申请是否获上交所受理；MiniMax辅导是否验收。
  • DeepSeek是否出现辅导、受理或正式招股文件。
  • 未来4–8周是否出现多个旗舰发行窗口重叠。

减仓 / 退出

  • 收盘跌破1.64–1.65且两日不能收复。
  • 反弹到1.90附近量价背离，半导体与科创宽度继续恶化。
  • 新股高估值扩散，但盈利和ETF资金没有跟上。
  • DeepSeek媒体传闻被证伪，或最终选择非科创板市场。

最终总结与评级

08 / VERDICT

现在低吸高抛，按供给波次升级，不等一个不存在的“全部上市日”

科创50正在经历连续换血：摩尔线程、沐曦已进指数，长鑫正在价格发现，宇树等待发行，智谱拟募资150亿元并申请科创板，MiniMax进入A股辅导，DeepSeek仍待证真。这提升长期AI全栈纯度，却延长短期资金消化期。策略上，1.76下方等待，1.76–1.83做小仓波段；站稳1.90且ETF份额扩张、未来4–8周供给不拥挤后，先升至40%–50%；只有至少两轮冲击被吸收、周线站稳并重回2.20，才考虑50%–65%成长核心仓。跌破1.64停止摊平。
