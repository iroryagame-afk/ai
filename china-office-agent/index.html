03 / COST

除 WPS AI 外，各产品均未公开单用户或单任务 token 消耗。下面用同一任务包和 OpenRouter 2026-08-02 可见列表价计算，只比纯模型 API 成本。

选择任务强度
唯一官方披露的真实量WPS AI：2,000 亿+ token / 日

以 8,013 万 MAU 简单相除约为 2,496 token / MAU / 日。分母不是 DAU，因此只能当平台渗透强度，不能当单活跃用户消耗。

长链 Agent400K 输入 + 30K 输出
若每人每月执行 20 次此类任务按 1 USD = 7.2 RMB 情景汇率；未含检索、沙箱、存储、并发和人工服务。

选型结论：没有一个“全场景最强”

04 / DECISION
国内通用 AGENT

WorkBuddy

适合已在微信、企微、腾讯文档中工作的个人与团队。优势是入口和连接，不代表已验证付费率。

原生 OFFICE

WPS AI / 灵犀

文档、表格和演示深度最强，并有 MAU 与 token 披露。更像带 Agent 的 Office，而非无边界的桌面操作系统。

研究与长文

Kimi Work

长上下文和多智能体调研能力强，但独立 Work 用户数与单任务成本未披露。

开发与生态

TRAE / 千问办公

TRAE 偏代码，阿里正将多个 Agent 整合为统一办公入口。现阶段需要将产品整合消息与已完成用户迁移分开。
