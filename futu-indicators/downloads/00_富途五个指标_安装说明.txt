富途五个指标安装说明
====================

一、安装前准备

1. 使用富途牛牛桌面端，不要在手机端创建指标。
2. 打开任意股票的K线页面。
3. 进入“指标”或“指标管理”，选择“新建指标”。
4. 每个文件必须单独新建一个指标，不要把五份代码合并在一起。
5. 粘贴代码后，必须先点击“测试指标”，通过后再保存和应用。

二、缠论 CLCUR V19

文件：01_主图_缠论_CLCUR_V19_原版.txt
语言：Python
对象：主图指标
建议名称：缠论当前周期V19
建议缩写：CLCUR
建议周期：日K、30分钟、5分钟

安装：
1. 新建“主图指标”。
2. 语言选择 Python，不要选 Mai Language。
3. 复制该TXT的全部内容并粘贴。
4. 点击“测试指标”，通过后保存。

说明：
- 红绿线为已确认笔，粉蓝区域为中枢。
- B?/S?、1B?/1S?、2B?/2S?、3B?/3S? 都是候选观察标记。
- 切换K线周期后，指标会按当前周期重新计算。

三、自动压力线 FTTL1

文件：02_主图_自动压力线_FTTL1_原版.txt
语言：Mai Language
对象：主图指标
建议名称：自动趋势线与形态轻量版
建议缩写：FTTL1
建议周期：日K、60分钟、30分钟

安装：
1. 新建“主图指标”。
2. 语言选择 Mai Language，不要选 Python。
3. 复制该TXT的全部内容并粘贴。
4. 点击“测试指标”，通过后保存。

说明：
- DOWN_RES 为下降压力线，UP_SUP 为上升支撑线。
- FLAT_RES/FLAT_SUP 为近似水平压力与支撑。
- TRI?/ASC-TRI?/DESC-TRI?/BOX? 是形态候选，不是自动买卖指令。

四、MACD 底背离高亮版 V1

文件：03_副图_MACD底背离_富途高亮版_v1_原版.txt
语言：Mai Language
对象：副图指标
建议名称：MACD底背离高亮版
建议缩写：MACDBD
建议周期：日K优先，分钟K需自行确认效果

安装：
1. 新建“副图指标”。
2. 语言选择 Mai Language。
3. 复制该TXT的全部内容并粘贴。
4. 点击“测试指标”，通过后保存。

说明：
- 显示 DIF、DEA、四色动能柱及底背离高亮。
- “底背离”只是反弹或反转观察，需结合趋势和价格确认。

五、BIAS20/60 五档冷暖逃顶指标

文件：04_副图_BIAS2060_五档冷暖逃顶指标_原版.txt
语言：Mai Language
对象：副图指标
建议名称：BIAS20/60五档拥挤度
建议缩写：BIAS2060
建议周期：仅日K

安装：
1. 新建“副图指标”。
2. 语言选择 Mai Language。
3. 复制该TXT的全部内容并粘贴。
4. 点击“测试指标”，通过后保存。

说明：
- 蓝线为BIAS20，红线为BIAS60。
- -8/-5/10/15/20 是五档冷暖阈值。
- 该指标必须使用日K，不要直接套用到分钟K。

六、KDJ VOL V3.1

文件：05_副图_KDJ_VOL_V3.1_BS高对比版_原版.txt
语言：Mai Language
对象：副图指标
建议名称：KDJ VOL V3.1
建议缩写：KDJVOL
建议周期：仅日K

安装：
1. 新建“副图指标”。
2. 语言选择 Mai Language。
3. 复制该TXT的全部内容并粘贴。
4. 点击“测试指标”，通过后保存。

说明：
- [B?] 为买入观察，[B] 为买入确认。
- [S?] 为下跌观察，[S] 为下跌确认。
- 这些只是视觉标记，不代表严格缠论买卖点。
- 指标默认按日K设计，周K和分钟K不能直接套用。

七、建议安装顺序

1. CLCUR V19（Python主图）
2. FTTL1（Mai Language主图）
3. MACD底背离（Mai Language副图）
4. BIAS2060（Mai Language副图）
5. KDJVOL（Mai Language副图）

同一个K线主图不建议同时叠加过多指标。CLCUR与FTTL1都属于主图，如图面太拥挤，请二选一显示。

八、常见问题

1. 第1行提示 invalid syntax：
   通常是 Python 和 Mai Language 页签选反。CLCUR用Python，其余四个用Mai Language。

2. 指标测试失败：
   记录富途显示的第一个出错行号和完整错误文本，不要盲目删减公式。

3. 主图太拥挤：
   优先只显示CLCUR或FTTL1中的一个，副图指标按需切换。

4. 分钟K上信号过多：
   BIAS2060和KDJVOL请回到日K使用；MACD底背离在分钟K上需另行检查噪音。

九、执行边界

- 所有指标都是研究和观察工具，不代表自动下单。
- 买卖标记必须结合行情、周期、量价、失效位和仓位纪律复核。
- 如果富途客户端“测试指标”未通过，不应当作已验证可用。
