## 权威边界

- 本文件是 CSNPK 正式页面、核心导航和退役入口的唯一清单。
- `.runtime/github/ai` 是公开发布仓库；页面生成器可位于股票工作区其他目录，二者必须分别核验。
- 页面可访问、页面数据已刷新、Git 已同步、Cloudflare 已部署和公网回读是不同验收门槛。
- 动态页面显示的数据日期与核验状态以页面自身标记为准，不得因 HTTP 200 推断数据为最新。

## 导航约定

- 编辑式全站导航按“股票 / A股工具 / 美股工具 / 市场观察 / 调研”分组；核心页面之间不得出现目标缺失或同名不同址。
- “冰神分享”使用独立顶层导航入口，固定放在“调研”之前；不收纳在“A股工具”下拉菜单中，首页 A股工具卡片可保留。
- “市场观察”下拉固定收纳“中韩美市场进度”和“财政风险溢价监控”；财政风险必须以长端、美元和扩散层共同确认，单一盘中异动不得升级红色。
- “美股大盘观察”归入“美股工具”，只汇总已核验的市场进度 US 分项、CNN 情绪、Cboe Put/Call、US Skew、RS Thrust/轮动与 FINRA 月频杠杆；必须保留各来源日期，不得伪装成同源同日数据。
- “X 作者图表共识”是 `/us-market/` 的辅助子页，入口固定放在父页；X 帖子和图表只能标为线索或待证真，必须与 OpenD 行情确认分层，不直接产生交易信号。
- 美股研究路径固定为 `/us-market/` → `/us-skew/` → `/csn/hot/` → `/rs-thrust/` → `/rotation/` → `/csn/`；`/ai-decision/` 保持跨市场进度页，不再承载该路径模块。
- `/csn/` 是美股研究路径的最终综合页：必须先通过同一完整收盘日硬门，再由美股大盘、财政风险、CNN贪恐与 Cboe Put/Call 决定进攻/中性/防守门槛和数量上限。
- “美股热门榜”必须作为股票分组中的独立入口，直接指向 `/csn/hot/`，不得仅藏在“美股严选”页面内部。
- `/bingshen/` 是 A股工具分组中的静态观察池与公式下载页；TN6 只按通达信包提供且不能直接导入富途，导入脚本只修改自选分组、不下单、不创建提醒。
- `/futu-indicators/` 与 `/bingshen/` 独立展示：前者只保留五个富途主副图代码，后者只保留冰神观察池和《冰神分享》TN6 包。
- “A股猎龙者信号表”属于外部工具入口，固定指向 Google Sheet `1XEVPTz6SOFWj_Krcp0evHJJU8e28LJ_oCdP6Y0_6-vw`。
- `/csn/hot/` 是 `/csn/` 的子页面，可以在股票分组中额外出现。
- `/ai-software-security-shovels/` 是固定 18 只股票的独立动态监控台；ANET 按软硬一体控制层归入软件。组内强度不是 `/rs-thrust/` 的正式分数，高弹性标的只有在市场、催化、趋势、量价、两日确认与盈亏比六门齐过时才允许升级买入动作。
- `/ai-hardware-shovels/` 是固定 24 只股票的独立动态监控台；ANET 不重复进入硬件池。轮动、加速度与组内强度统一以 SPY 为基准，AAOI 等高弹性标的只有在市场、板块、催化、趋势量价、两日确认与盈亏比同时通过时才允许升级买入动作。
- `/ai-decision/` 可以使用紧凑数据源导航，并保留 RS Thrust、US Skew、轮动雷达和投研导航。
- 新增正式动态页时，必须同时更新本注册表、首页入口、相关生成器和所有采用全站导航的页面。
- 新增长期报告时，不加入动态页清单；按 `docs/report-nav-policy.md` 更新 `nav/reports.json`。

## 首页三工具共振

- “强烈推荐”仅在同一普通股票或普通 ETF 同时被美股严选、RS Thrust、轮动雷达三个工具选中时显示。
- 只有两个工具重合时不展示强烈推荐，也不占用首页高度。
- 杠杆 ETF、反向 ETF 和 ETN 不与普通股票、ETF 混排；若形成三工具重合，只进入“高风险战术工具”，并标注仅适合短线。
- 没有三工具重合时，整个模块保持隐藏。

## 视觉与生成基线

- 全站保持纸张底色、宋体标题、藏蓝/朱砂/金色语义色；桌面主内容与导航最大宽度为 1480px，下拉菜单宽度为 250px。
- 页面本身不得出现横向溢出；密集表格只允许在自身容器内滚动。移动端交互目标不得因压缩布局而不可点击。
- 视觉或模板更新不得覆盖更新的数据日期、验证标记、交互能力、正式入口和退役路由；生成器与发布静态页必须同轮更新。
- `/csn/` 只公开紧凑的“美股综合优选”；旧表姐美股严选标题、状态栏、筛选器、搜索和300只明细表继续退役。模型按强度轮动30、趋势位置25、热度主线15、量价结构10、专项监控10、风险收益10计分；目标动态5–10只，但不得为凑数降低门槛。普通股票和标准ETF可入选，杠杆、反向ETF和ETN排除；同赛道最多2只，同公司多股份类别只保留1只。X作者共识只作旁证，不直接加分。
- `/csn/hot/` 与 `/rotation/` 保持正式入口；`/yanpan-ai/` 已退役，不得由旧模板恢复。

## 自动刷新边界

- CSNPK 自动刷新每次先读本注册表，只维护“正式动态页面”；已退役路径不得被旧生成器或旧定时任务恢复。
- A 股、韩股和美股分别以各自最新完整交易日核验；`/ai-decision/` 允许不同市场保留各自来源日期，不得强行伪装成同日。
- 任一市场没有新完整交易日时，该市场分组应报告 `no_new_market_date` 并保留线上已验证版，不得阻塞其他市场的独立刷新。
- 长期调研报告是静态内容，不纳入每日行情刷新；新增或修订时另行按 `docs/report-nav-policy.md` 发布。

1. 对仓库内正式 HTML 做内部链接、重复 ID、标题、语言、viewport、外链安全和脚本语法检查。
2. 运行 `python3 scripts/validate_report_nav.py`，并检查 `nav/reports.json` 中每个报告地址。

5. 对本轮修改的公开文件比较线上与提交内容哈希。
