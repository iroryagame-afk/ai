# 股票分析规则

## 输出原则

- 结论先行：明确现在投、等回调、等确认或不投，并区分观察仓与确信仓。
- 区分事实、推导和判断；未实际核验的数据标记为“未核验”。
- 最新价格、财报、公告、政策、管理层、一致预期和市场数据必须重新核验并标注截至时间。
- 截图、社交媒体和二手报道只作线索，优先追溯公司 IR、监管文件、交易所、公告或可信数据源原文。
- 不把同比增长直接写成超过预期；超过预期必须存在可比的一致预期、相同指标口径和对应截至时间。

## 默认研究框架

1. 投资结论与当前动作边界。
2. 产业/主题定位与核心产品阶段。
3. 收入、利润率、现金流、资本开支和指引变化。
4. 竞争格局、供应链位置、催化剂和主要风险。
5. 论文强化、弱化和证伪条件。
6. 估值与 6–12 个月保守、基准、乐观目标价。
7. 纯度、弹性、确定性、风险评级及相对排序。

## 技术点位

- 标注行情日期、盘中/收盘类型、周期、复权方式和数据源。
- 观察区、触发位、确认位、失效线和压力位必须说明推导依据。
- 同时给出量价确认与失效条件；A 股明确 T+1 约束。
- 不输出没有依据的伪精确孤立数字。

## 动作边界

- 研究结论不构成投资建议。
- 页面、提醒和观察条件不代表下单。
- 未经明确授权不得写提醒、调整组合、发送外部消息或执行交易。
