# CSNPK 四段式研究通行证

状态：已作为页面统一交互规范发布。

## 固定决策顺序

1. **市场闸门**：回答当前允许进攻、中性观察还是防守，只决定仓位上限和新仓权限。
2. **资金方向**：回答市场关注什么、相对强度流向哪里；没有真实资金数据时不得简称为资金流。
3. **轮动阶段**：回答标的处于改善、领先、转弱还是落后，以及前一交易日到当前的已发生迁移。
4. **个股执行**：继承上游闸门，结合趋势、量价、位置、事件、盈亏比和失效条件输出动作。

## 通行证最小字段

- `asOf`：行情或评分日期；
- `verifyStatus`：已核验、条件核验或未核验；
- `marketGate`：进攻、中性或防守及其依据；
- `directionEvidence`：资金、热度或相对强度证据及口径；
- `rotationPhase`：统一四象限状态和基准；
- `executionAction`：当前动作、触发和失效条件；
- `benchmark`：SPY、QQQ、SOXX、中证全指等，不同基准坐标不得直接比较。

上游日期落后、验证失败或闸门未通过时，下游动作只能保持或降级。

## 统一轮动词典

| 标准状态 | 数据枚举 | 含义 |
| --- | --- | --- |
| 改善 Improving | `落后加速` | 仍相对落后，但动能改善 |
| 领先 Leading | `领先加速` | 相对领先且继续加速 |
| 转弱 Weakening | `领先减速` | 仍相对领先，但动能降温 |
| 落后 Lagging | `落后减速` | 相对落后且继续恶化 |

旧称 `落后修复` 只作为展示别名，数据枚举统一为 `落后加速`。

## 页面职责

### 美股

- `/us-market/`、`/us-skew/`：市场闸门与风险修正；
- `/csn/hot/`、`/rs-thrust/`：热度发现与相对强度方向；
- `/rotation/`：全市场轮动阶段；
- `/csn/`、软件/硬件监控台：个股执行。

### A 股

- `/a-share-market/`：市场闸门；
- `/a-share-market/etf/`、`/a-share-thrust/`：资金承接与相对强度方向；
- `/a-share-rotation/`：轮动阶段；
- `/mda100/`、A 股软件/硬件监控台：个股执行并遵守 T+1。

## 交互边界

- 主雷达保留全量坐标，默认只显示重点标签，可切换全部标签；
- 箭头只表示前一交易日到当前交易日，不表示预测；
- 点位、标签和表格行共用同一选中状态；
- 轮动象限不能单独产生买点，执行动作必须继承市场闸门。
