# csnpk 投研报告导航维护规则

## 适用范围

`https://csnpk.com/nav/` 是所有已公开、非每日更新投研报告的统一入口。它覆盖专题策略、行业研究和公司研究，不承担实时行情或动态数据门户职责。

## 唯一清单

`nav/reports.json` 是导航页的唯一数据源。新增报告时登记一条对象，字段如下：

- `id`：稳定、唯一的英文标识；公开标题变化时通常不改。
- `date`：首次公开日期，格式必须是 `YYYY-MM-DD`。
- `title`：读者在导航页看到的完整中文标题。
- `url`：从 `/nav/` 出发的相对路径，使用 `../report-path/` 形式。
- `category`：只能是 `行业研究`、`主题策略` 或 `公司研究`。
- `tags`：用于搜索的非空短标签数组，建议 4-7 个。

清单按日期倒序维护。相同日期可按重要程度排序。

## 收录与排除

收录：

- 可长期阅读的专题投资框架或策略报告。
- 行业、产业链和关键材料研究。
- 独立公司深度分析。

排除：

- `CSN`、A 股严选、轮动雷达等每日选股或动态更新页。
- 已退役入口，例如 `csn2`、`earnings`。
- 已退役或兼容路径。
- 其他动态资金流页面。
- Skill 包、下载页、工具页。
- 儿童手册等非投研内容。
- 仅存在于本地、公开 URL 尚未验证成功的报告。

## 发布流程

1. 把报告放到稳定、可读的 `csnpk.com/<path>/` 路径。
2. 在同一分支更新 `nav/reports.json`。
3. 运行 `python3 scripts/validate_report_nav.py`，必须得到 `OK: <n> report entries validated`。
4. 本地打开 `/nav/`，验证搜索、分类筛选、报告总数与目标链接。
5. 发布报告和导航修改。
6. 用 cache-busting URL 回读公开页面，例如：
   - `https://csnpk.com/nav/?v=<timestamp>`
   - `https://csnpk.com/nav/reports.json?v=<timestamp>`
   - `https://csnpk.com/<report-path>/?v=<timestamp>`
7. 确认公开 JSON 中存在新记录，导航页面能够按标题或标签搜索到它。

只有报告 URL、导航页和公开 JSON 均已成功回读，才能宣告发布完成。

## 删除和路径变更

- 删除公开报告时，同一提交删除对应清单记录。
- 更换路径时，同一提交更新 `url`，并核验新链接；若保留旧路径重定向，也以新规范路径为准。
- 修改标题、分类或标签时直接更新清单，不改变稳定 `id`。
- 校验器发现重复 ID、重复 URL、排除页面或本地目标缺失时，必须先修复再发布。
