# CSNPK 页面与视觉规范

## 页面边界

- 正式页面、路由、导航分组和退役入口以 `docs/csnpk-page-registry.md` 为准。
- 新增长期研究报告必须同时更新 `nav/reports.json`；动态页和临时分享图片不得自动进入报告导航。
- 修改静态页时同步修改对应生成器，避免下次生成覆盖修复。
- 子路径页面不得依赖错误的根绝对资源地址；发布后逐项检查 CSS、JS、JSON 和图片路径。

## 视觉基线

- 沿用纸张底色、宋体标题、藏蓝/朱砂/金色语义色。
- 桌面主内容与导航最大宽度遵循页面注册表；密集表格只能在自身容器横向滚动。
- 390px 移动端必须可阅读、可点击、无页面级横向溢出。
- 颜色不能成为状态的唯一表达方式；关键状态同时使用文字或图标。
- 数据日期、验证状态、来源和风险提示不得因视觉改版被隐藏或删除。

## 页面交付检查

- 页面标题、描述、语言、viewport 和 canonical 路径正确。
- 导航、筛选、折叠、标签切换和外链可用。
- 空数据、部分数据、加载失败和过期数据均有明确状态。
- 桌面与移动端截图或检查记录写入 PR；未完成视觉 QA 时明确标记。
