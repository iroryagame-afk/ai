# CSNPK 发布验收清单

## 数据门禁

- [ ] 页面数据日期、完整市场日和时区已核验
- [ ] 主数据源硬门通过，覆盖率和失败项已记录
- [ ] 财务实际值与一致预期口径可比
- [ ] 未核验、部分核验和过期数据已明确标注

## 变更门禁

- [ ] 使用独立分支或干净 worktree
- [ ] `git diff --check` 通过
- [ ] 只暂存 Issue 授权的 intended files
- [ ] 没有包含凭据、临时文件或其他任务改动
- [ ] 本地构建、链接、脚本、JSON 和导航检查通过

## PR 门禁

- [ ] PR 关联对应 Issue
- [ ] PR 记录数据期间、截至时间、来源和未核验边界
- [ ] PR 列出页面、图片、数据文件和测试结果
- [ ] 部署授权已在 Issue 中明确勾选

## 部署门禁

- [ ] 部署对象是已推送的明确 Commit
- [ ] 部署版本或平台版本号已记录
- [ ] 使用 cache-busting URL 回读 HTML、Markdown、JSON 和图片
- [ ] 必要文件与 Commit 内容或哈希一致
- [ ] 正式页面、`/nav/`、`nav/reports.json` 和相关重定向按范围验收
- [ ] 桌面与 390px 移动端视觉检查完成，或明确标记未核验原因

## 完成门禁

- [ ] Issue 留言包含完成、未完成、数据时点、来源、判断、产物、线上地址和下一步
- [ ] `tasks/current/issue-<编号>.md` 已更新
- [ ] 只有全部发布门禁通过时才标记 `published_verified`
- [ ] 硬门失败时线上旧版保持不变
