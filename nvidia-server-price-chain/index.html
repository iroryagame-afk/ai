英伟达服务器涨价：谁赚到钱，谁吞下成本

真正的多头不是“所有 AI 硬件”，而是拥有存储定价权的上游；真正的压力也不只是云厂商，而是无法把成本及时转嫁、又要承担库存和融资的中游与算力运营商。

核验日：2026-08-23（北京时间）事件状态：高可信报道，尚非公司公告范围：美股 + A股不含实时股价与买点

结论先行：存储最直接，整机最容易“增收不增利”

美股研究顺序：MU → NVDA → AVGO → DELL/SMCI → CRWV/NBIS。 A股研究顺序：澜起科技 → 江波龙/德明利 → 兆易创新 → 工业富联/浪潮信息 → 英维克 → 寒武纪。 不追“服务器涨价”四个字；先确认涨价是谁发起、谁收钱、谁承担内存与融资成本。

事件判断偏多上游，分化中下游NVDA 偏利好但非无风险；OEM 中性偏多；AI 云与 NeoCloud 成本压力上升。

先把标题拆对

01 / VERIFY
已核验

报道说了什么

Bloomberg 援引知情人士称，部分搭载 NVIDIA AI 芯片、预计明年初交付的服务器系统将涨价，很多情况下超过 15%，幅度取决于芯片代际和内存配置。

未被确认

不是统一官宣

Reuters 转述时明确写明无法独立核实；截至本页核验时，未找到 NVIDIA 对 Vera Rubin / Grace Blackwell 服务器普遍涨价的正式公告。

官方旁证

内存确实能触发调价

NVIDIA 2026年2月已因全球内存供应约束，把 DGX Spark 官方建议零售价从 3,999 美元调至 4,699 美元，但这是不同产品，不能替代本次服务器涨价确认。

产业证据

成本压力并非空穴来风

TrendForce 预计 3Q26 Server DRAM 合约价季增 13–18%，且 2026 下半年至 2027 下半年仍逐季上涨；同时 AI 服务器需求预测被上调。

最重要的措辞修正：“搭载英伟达芯片的服务器被通知涨价”不等于“英伟达独自拿走全部涨幅”。涨价可能由 GPU/系统平台、DRAM/HBM、企业级 SSD、网络、电源、散热及整机交付成本共同驱动。

利润传导：涨价不等于利润增加

02 / MECHANISM
存储原厂供不应求、ASP 上行，最强定价权
GPU / 平台尝试转嫁成本，维持平台毛利
服务器 OEM收入抬升，但低毛利与库存占资
云 / NeoCloud资本开支、折旧和融资成本上升
模型与终端客户算力租金上调、优化模型或转向 ASIC
判断股票只看三个问题：合同能否调价、库存是低价还是高价、客户会不会因总拥有成本上升而延后采购或改用自研 ASIC。

美股：直接受益与成本承压分开看

03 / US

事件本身最直接利好内存定价权；NVDA 的正面含义是需求和成本转嫁能力仍强，但下一步必须由毛利率、订单量和客户自研 ASIC 节奏验证。

优先级股票方向传导逻辑利润兑现判断核心风险 / 证伪产品阶段
1MU直接利好美国上市标的中最直接的 DRAM/HBM 供给方；客户需求高于供给，存储战略地位上升。ASP 与产品结构最容易进入利润高价反噬需求、客户降配、后续扩产导致周期反转。规模放量期
2NVDA偏利好若系统能把存储成本转嫁给客户，说明平台定价权和需求韧性仍强。高毛利底盘强，但系统化交付会稀释结构8月26日财报若毛利指引下修；客户加速 ASIC；订单因总价上升延后。规模放量期
3AVGO中长期利好英伟达系统总拥有成本上升，提高超大客户自研 AI ASIC 的经济动机；Broadcom 定制加速器与 AI 网络收入已高速增长。是替代路径受益，不是本次涨价收入ASIC 仍同样消耗 HBM/DRAM；软件迁移和量产节奏慢于预期。规模放量期
4DELL增收 / 混合AI 服务器订单与积压强，整机 ASP 上行可放大收入和服务基数。绝对毛利可增，毛利率未必升AI 服务器产品组合曾压低毛利率；成本转嫁滞后和备货占资。规模放量期
5SMCI高弹性 / 混合机柜级 AI 系统量价齐升带来收入弹性，液冷和整柜交付提高单柜价值。取决于客户结构与采购价差FY26 全年毛利率 10.8%；新品加急、关税和存货减值会吞噬涨价。规模放量期
6VRT / ETN间接受益机柜功率和液冷渗透率提升，电力与热管理单柜价值增长。受益于继续建机柜，不是服务器涨价本身高系统价格导致项目延期；施工、电网或融资成为新瓶颈。规模放量期
7MSFT / GOOGL / AMZN / META短空长混合短期资本开支与折旧压力上升；长期可通过云价、利用率、模型优化与自研芯片缓冲。强资产负债表，承压但不等于利润必降算力租金无法传导；AI 收入低于折旧和资金成本。标准化普及期
8CRWV / NBIS偏利空更依赖外购 GPU 系统与外部融资，单 MW 资本开支和折旧上升。必须靠长期合同和更高租金覆盖固定价合同、利用率下滑、融资成本高、设备迭代导致残值下降。规模放量期

A股：别把“存储概念”当成 HBM

04 / A-SHARE

A股没有可与 MU、SK hynix、Samsung 直接对标的高端 HBM 原厂。最直接的产业映射是服务器内存接口与模组生态；国产算力是替代期权，不是这次涨价的当期利润受益。

优先级股票方向纯度传导逻辑核心风险 / 证伪产品阶段
1澜起科技 688008最直接受益高DDR5 RCD、MRCD/MDB 等服务器内存互连芯片直接受益于服务器内存条数、带宽和代际升级；典型 AI 服务器内存模组数约为通用服务器 2 倍。它赚的是接口芯片量与规格升级，不直接赚 DRAM 颗粒涨价；客户集中、代际切换节奏。规模放量期
2江波龙 301308条件式利好中高企业级 eSSD 与 RDIMM 已形成收入并推进国产客户，服务器存储需求与价格上行提供量价环境。颗粒外购，高价库存、客户验证和成本转嫁决定毛利；并非 DRAM 原厂。试点部署期 → 规模放量期
3德明利 001309高弹性利好中企业级存储客户与产品验证推进，内存条业务高增长；存储涨价与库存周期带来弹性。颗粒采购与库存价格波动大，营收弹性不等于稳定毛利。客户认证期 → 试点部署期
4兆易创新 603986外溢利好中低国际原厂转向 HBM/DDR5，挤出利基型 DRAM、SLC NAND 供给，公司已披露相关产品量价受益。主营不是 AI 服务器 HBM 或主流 Server DRAM；属于产能挤出和周期外溢。规模放量期
5工业富联 601138增收 / 混合高云服务商 AI 服务器收入已同比增长超过 3 倍，GPU 与 ASIC 方案均增长；整机价升可放大收入。2025 年云计算毛利率仅 5.73%；年报明确提示原材料涨价若无法传导将压低毛利率。规模放量期
6浪潮信息 000977需求利好 / 成本压力高AI 服务器与智算系统需求延续，国产市场系统集成与交付规模受益。服务器行业竞争激烈、净利率低，备货占资；海外 NVIDIA 链条并非其唯一或直接收入来源。规模放量期
7英维克 002837间接受益中高高功率机柜带动冷板、CDU 与数据中心液冷渗透；公司披露将在液冷智算中心和液冷服务器加大拓展。受益来自机柜功率与部署量，不来自内存涨价；项目延期会延后确认。规模放量期
8寒武纪 688256替代期权中NVIDIA 系统 TCO 上升提高国产加速器的相对经济性和供应安全价值。软件生态、性能、供货和客户验证决定替代，不可把“更便宜”直接写成订单。试点部署期 → 规模放量期
A股龙一 / 龙二：直接产业映射龙一为澜起科技；高弹性龙二在江波龙与德明利之间，但两者都要把“颗粒涨价带来的库存收益”与“采购成本侵蚀毛利”分开。工业富联是整机规模龙头，不是本事件利润弹性龙头。

三种情景：决定谁最终兑现

05 / SCENARIO

基准：涨价成功，订单不掉

  • 存储原厂 ASP 上行，MU 最直接；
  • NVDA 把成本传导，毛利率大体守住；
  • DELL/SMCI/工业富联收入增加，但毛利率改善有限；
  • 云厂商以更高利用率、租金或自研 ASIC 对冲。

乐观：供给约束证明需求极强

  • 明年初系统订单没有因 15%+ 涨价取消；
  • Server DRAM/HBM 长约锁量，存储超级周期延长；
  • 液冷、电力、互连等单柜价值同步提升；
  • A股澜起、企业级存储和液冷进入更快规模放量。

悲观：价格破坏需求

  • CSP 延后订单或降低内存配置；
  • AI 云无法提价，利用率和融资成本恶化；
  • OEM 因固定合同或高价库存出现毛利挤压；
  • ASIC 替代加快，NVDA 定价权从利好转为份额风险。

最大误区：把所有算力股当利好

  • 光模块、PCB、液冷只在部署量不受损时受益；
  • 服务器 ASP 上升不能证明代工厂赚到更多利润；
  • 国产替代需要性能、生态、供货与客户认证；
  • A股存储模组商不是 HBM 原厂。

CONTRACT

MEMORY

DEMAND

订单取消与降配

关注客户是否从 96/128GB RDIMM 下调至 32/64GB，或推迟明年初系统交付。

ASIC

自研芯片迁移速度

Google、AWS、Meta 与其他大客户的 ASIC 部署是否从成本对冲变成份额替代。

A-SHARE

收入而非送样

澜起看 MRDIMM / DDR5 出货；江波龙、德明利看企业级产品收入和毛利；寒武纪看真实客户与回款。
