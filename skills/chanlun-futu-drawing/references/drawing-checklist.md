# 缠论图生成检查清单

生成图前：

- [ ] 确认代码映射，例如 `01888` -> `HK.01888`。
- [ ] 确认数据源：优先 Futu OpenD。
- [ ] 确认周期：默认 30分钟；用户要求 4小时图时用 `K_240M` 并沿用当前标的重画。
- [ ] 若 OpenD 不支持该市场/代码，例如韩国 `KR.*` 或 App 内部指数别名，必须明确写“OpenD 不支持/未核验”，并标注替代数据源。
- [ ] 若使用美股盘前/盘后价，必须和正式K线分开标注，不得混入严格中枢计算。
- [ ] 获取最新快照：最新价、更新时间、日内高低。
- [ ] 获取足够 K 线：至少覆盖最近两个中枢和当前箱体。

画图时：

- [ ] 已确认中枢用实线框，并标 `ZD/ZG`。
- [ ] 已确认中枢要醒目：优先使用半透明黄色带状区域、粗边框、上下沿横线。
- [ ] 如果有多个严格中枢，必须全部列出，不能只画最近一个。
- [ ] 主图每个中枢框必须标出编号，例如 `中枢A/B/C` 或 `中枢D/E/F/G/H/I`，并与右侧点位表逐一对应。
- [ ] 中枢编号必须放在框外沿、框角或附近空白区；如需引导，用短虚线引回中枢框，不得遮挡 K线、笔线、中枢边界或买卖点。
- [ ] 笔内横盘/次级别观察用灰色虚线框，不要混用黄色严格中枢框。
- [ ] 离开旧中枢后的新区域，若未形成本级别“三笔重叠”，必须写“新中枢未形成 / 走势未完美”。
- [ ] 旧中枢下方的反抽只能写“反抽/回抽旧中枢/构筑新中枢观察”，不能写成反转或走势完成。
- [ ] 默认做“双区图”：上方历史回溯所有中枢，下方放大当前最近中枢与未完成笔。
- [ ] 未确认区域写“箱体/中枢雏形”，不要写“中枢”。
- [ ] 买卖点用 `S1/S2/S3/B?/B2`。
- [ ] 买卖点不要覆盖K线：用小点标实际位置，再用虚线引到旁边说明框。
- [ ] 观察点说明框必须写“观察/未确认”，不能写成确认买卖点。
- [ ] 5分钟等密集图的买卖点说明框优先放主图空白区；空白不够时再放右侧信息栏。
- [ ] 右侧放关键点位表，避免主图标签重叠。
- [ ] 右侧或底部必须放“数值来源/算法来源”：说明 `ZD/ZG`、当前价、修复位、破位位、支撑位分别怎么来。
- [ ] 严格中枢点位按 `ZD=max(重叠笔低点)`、`ZG=min(重叠笔高点)` 标注；截图判读数字必须写“约”。
- [ ] 下半部分画强/中/弱三路径。
- [ ] 强/中/弱三路径必须写具体触发点位和处理纪律，不要只写方向判断。
- [ ] 若涉及A股持仓操作，提醒当日新买不可卖，处理建议只针对可卖老仓。

输出前：

- [ ] 检查文字是否重叠。
- [ ] 检查中枢是否一眼可见，是否容易误解为“只有一个中枢”。
- [ ] 检查主图中枢编号是否齐全，是否和右侧表的 `A/B/C` 或 `D/E/F/G/H/I` 完全对应。
- [ ] 检查历史中枢和当前中枢是否分别呈现。
- [ ] 检查明显笔内箱体是否被漏掉；若标出，必须注明“非本级别严格中枢”。
- [ ] 检查是否把旧中枢误写成当前新中枢；新区域未形成三笔重叠时，必须标“走势未完美”。
- [ ] 检查 `S2` 是否遗漏。
- [ ] 检查 `B?` 是否被误写成确认买点。
- [ ] 检查 `B?/S?` 标注是否遮挡K线或笔线；若遮挡，改成虚线引出。
- [ ] 检查主图区说明框是否遮挡K线、中枢框或笔线；若遮挡，移到主图空白区或图外。
- [ ] 检查是否把 `80.6` 等普通参考位误写为中枢边界。
- [ ] 检查图上每个关键数字是否有来源说明，且说明没有遮挡主图。
- [ ] 检查非 OpenD 数据是否已标“非OpenD核验/截图判读/公开源”。
- [ ] 检查正式K线价和盘前/盘后参考价是否分开。
- [ ] 检查 final 是否说明“不构成投资建议”。
