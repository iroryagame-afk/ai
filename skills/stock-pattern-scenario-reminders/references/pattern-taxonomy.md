# 技术形态分类与证据规则

这份分类用于生成“候选结构”，不是把价格强行塞进某个名字。先找结构线和关键点，再比较主判与次选；如果两者证据接近，结论写“混合/未决结构”。

## 第一层：反转结构

| 形态 | 最低结构要求 | 确认线 | 常见反证 |
|---|---|---|---|
| 头肩底 / 头肩顶 | 肩-头-肩与两个颈线触点 | 颈线收盘突破/跌破 | 右肩越过头部、颈线触点不足 |
| 双底 / 双顶 | 两次同区测试，中间有明显反弹/回落 | 中间峰/谷 | 两个极值相距太近或差异超过约 1 ATR |
| 三重底 / 三重顶 | 三次同区测试，时间跨度足够 | 区间边界 | 第三次测试没有拒绝或量价改善 |
| 圆弧底 / 圆弧顶 | 斜率逐步变化、持续时间较长 | 碗沿/平台边界 | 实际更像箱体或单次 V 形反弹 |
| V 形底 / V 形顶 | 急跌急升或急升急跌，拐点集中 | 失地收复/关键均线 | 无回踩，风险收益比不可执行 |
| 杯柄 / 倒杯柄 | 杯体回撤有序，柄部较浅且波动收缩 | 杯沿 | 柄部过深、杯体过尖或左右极不对称 |
| 岛形反转 | 两侧存在可核验跳空，孤立交易区 | 第二个跳空 | 缺口已被实体快速回补 |

## 第二层：整理与延续结构

| 形态 | 结构线特征 | A 路径 | C 路径 |
|---|---|---|---|
| 箱体 / 平台 | 近水平上下沿，多次触碰 | 顺原趋势突破 | 反向跌破/突破 |
| 上升三角 | 上沿近水平，下沿抬高 | 上破上沿 | 跌破抬高低点连线 |
| 下降三角 | 下沿近水平，上沿降低 | 下破下沿 | 上破降低高点连线 |
| 对称三角 | 高点降低、低点抬高 | 沿突破方向确认 | 回到三角内并破反向边界 |
| 牛旗 / 熊旗 | 明确旗杆 + 逆趋势窄通道 | 顺旗杆方向突破 | 破旗面反向边界 |
| 三角旗 | 明确旗杆 + 快速收敛 | 顺旗杆方向突破 | 收敛区反向破位 |
| 上升楔形 / 下降楔形 | 两条同向但收敛的趋势线 | 以实际突破方向为准 | 回到楔形并破另一边 |
| 上升/下降通道 | 两条近似平行趋势线 | 顺趋势延续或通道突破 | 破坏主趋势线 |
| VCP 波动收缩 | 多轮回撤幅度和成交量递减 | 放量突破枢轴 | 波动重新扩张并破最后收缩低点 |

## 第三层：辅助信号，不独立命名主形态

- K 线组合：锤头、吞没、早晨/黄昏之星、乌云盖顶、三只乌鸦等，只作为关键位附近的确认信号。TA-Lib 可提供候选标记，但不能绕过趋势和位置。
- 指标背离：RSI/MACD 顶背离或底背离必须同时写出价格新高/新低和指标未确认的对应日期。
- 缺口：区分突破、持续、衰竭和普通缺口；没有成交量与位置证据时只写“待分类缺口”。
- 相对强弱：比较标的与市场基准的 20/60 日收益，判断个股突破是否得到相对强势支持。
- 量价：突破量能、回踩缩量、下跌放量属于证据组件，不是单独买卖信号。

## 第四层：默认不自动给结论的高级结构

- ABCD、Gartley、Bat、Butterfly 等谐波形态：只有各腿比例落入预先声明的容差范围时才标注；否则不命名。
- 艾略特波浪：主观分浪分歧大，默认只作为用户明确要求后的附录，不进入提醒主线。
- 纯截图视觉模型：可用于发现候选区域，但必须回到 OHLCV 数据重算日期、价格与结构线。

## 结构质量评分（不是胜率）

总分 100，只表示“这个命名有多扎实”，不表示未来上涨/下跌概率：

- 几何与极值关系 25：关键点顺序、相对高低、斜率是否符合定义。
- 触点与持续时间 15：边界触点数量及形态是否有足够时间展开。
- 量价证据 15：突破放量、回踩缩量、关键位拒绝是否存在。
- 突破/跌破确认 15：完成 K 线、缓冲、连续站稳/跌破。
- 回踩/反抽确认 10：决策区是否完成成功回测。
- 动量与背离 10：RSI/MACD 是否确认或出现可解释背离。
- 市场与相对强弱 10：指数环境及 20/60 日相对表现。

质量档：`high >= 75`、`medium 55–74`、`low 35–54`、`insufficient < 35`。任何缺失项按 0 分并列入 `missing_evidence`，不要用猜测补齐。

## A/B/C 语义

- A：主形态得到确认后的方向路径。底部/多头延续通常是 `bullish`；顶部/空头延续通常是 `bearish`。
- B：形态未决、假突破或回到结构内部，固定为 `range`。
- C：A 的反向失效路径，方向必须与 A 相反。

因此，头肩顶的 A 可以是向下有效跌破、C 是向上收复颈线；不能把所有 A 都画成上涨。
