# 卖方预期差财报图

## 目标

把一份业绩公告压缩成卖方 TMT 晨会第一页：

- 3 秒看懂是否超预期。
- 10 秒看懂卖方是否要上修盈利预测。
- 20 秒看懂公司是否值得买，以及已有仓位、新资金分别怎么做。

最终交付包括：约 200 字聊天正文分析，以及一张 9:16 手机竖屏图。默认不生成 PDF。

## 工作流

### 1. 建立证据底稿

按 `references/data-contract.md` 取数并记录来源、发布日期、统计口径和时间戳。

必须先获得：

1. 公司官方公告或定期报告。
2. 最新已核验价格；涉及点位时必须连接 Futu OpenD。
3. 卖方一致预期：来源日期、分析师数量、全年利润和 EPS。
4. Q1、H1/全年数据，以及可推导的 Q2 单季数据。
5. 公司所有重要展望，包括利好和利空。

若没有可靠一致预期，明确写“暂无可靠一致预期”，不得用模型预测冒充卖方共识。若引用市场 Whisper，必须标明来源和日期；没有可靠来源就写“无可靠 Whisper”。

### 2. 判断预期差

分别回答：

- 卖方视角：全年盈利预测上修、不变还是下修？
- 买方视角：当前股价是否已反映，已有仓位和新资金如何处理？
- 业绩质量：扣非利润、现金流、一次性损益和利润率是否支持表面增速？
- 节奏：Q2 是否环比加速，还是仅由低基数造成？

不得把“卖方上修”直接等同于“股价一定上涨”。

### 3. 先判断值得不值得买，再判断现在怎么买

必须输出两个彼此独立的结论：

1. **投资价值结论**：值得买 / 仅观察 / 不值得买。它回答公司质量、盈利上修和中期赔率是否成立。
2. **执行结论**：直接买 / 回调买 / 确认买 / 暂不买。它回答在当前价格和技术位置如何下单。

股价当日大涨只会改变执行结论，不能自动把“值得买”降成“不值得买”。例如，公司仍值得配置但当天价格跳涨，应写“值得买｜回调买”，而不是含糊地写“等待”。昨天在低价位给出买入、今天上涨后改为持有或回调买并不矛盾，必须解释是价格改变了赔率。

用基准情景而不是乐观情景决定动作：

- **直接买**：当前价对应基准目标仍有约 15% 以上空间，盈利预测上修有证据，利润质量不低，失效线通常在买入价下方约 8%–10%以内。默认先建观察仓，不等于满仓。
- **回调买**：公司值得买，但当前价把基准空间压到约 15%以下；给出一个可成交的回调区，使基准空间恢复到约 15%以上，并标明失效线。
- **确认买**：产业和预期差成立，但利润质量、客户认证、产能爬坡或卖方覆盖仍需一个明确事件确认；写清确认条件。
- **暂不买**：即使回到近期合理支撑，基准空间仍不足，或利润质量/数据可信度无法支撑买入。

阈值是决策锚点而非机械公式。高波动公司需要更高安全垫；高确定性龙头可以略低，但必须说明理由。

### 4. 给出可执行操作

操作结论必须拆成两栏：

- **已有仓位**：加仓、持有、减仓、退出四选一，并给出触发条件。
- **新资金**：直接买、回调买、确认买、暂不买四选一，并给出价格区间或确认条件。

“不追”或“等待”不是完整指令。分别改写为“回调至某区间买”“满足某条件确认买”或“暂不买”，并说明原因。

批量分析时，必须按“新资金吸引力”排序并指出：首选、次选、暂不买。若没有适合当前价直接买的公司，也要选出最值得回调买或确认买的一家；只有所有公司在合理回调区仍无正赔率时，才允许结论为“全部暂不买”。不得为了显得积极而强行推荐不满足条件的公司。

止损或失效纪律独立成醒目的红色双边框。价格点位只有在 OpenD 已连接并完成核验后才能写入；否则标注“点位未核验”，不填猜测数字。

### 5. 形成正文结论

正文约 200 字，结论先行，并包含：

- 产业/主题定位与核心产品阶段。
- 纯度、弹性、确定性、风险评级。
- 同产业相对排序或龙一/龙二判断。
- 保守、基准、乐观三档 6–12 个月研究型目标价。
- 重要展望及其来源边界。

### 6. 制作竖屏图

严格使用 `references/visual-template.md` 的层级和样式；可参考 `assets/layout-reference.svg`，但不能复制其中任何公司或数字。

优先用 HTML/SVG 等确定性排版生成含中文文字的最终图。若使用图片生成模型，必须把文字作为精确文案提供，并在生成后逐字执行 `references/copy-audit.md`；发现错字、重复、漏项或数字冲突就修订，不得直接交付。

### 7. 交付前验收

以下任一项不通过，都不交付：

- 公告、卖方一致预期、价格三类来源边界清楚。
- 归母与扣非、单季与累计、实际与预测没有混用。
- 已有仓位和新资金的动作不同栏、不同颜色、没有同义重复。
- “是否值得买”与“当前怎么买”均已明确，不用涨幅替代投资价值判断。
- 批量分析已经给出相对排序和首选，不出现无差别的统一等待。
- 重要利好与利空展望均已检查。
- 全图无重复标题、重复结论、重复数字和残留旧版本文字。
- 中文字体、字号、留白适合手机阅读。

## 图内固定信息顺序

1. 一句话结论：超预期程度 + 卖方动作 + 投资价值 + 执行动作。
2. ACTION PLAN：已有仓位与新资金分别怎么做。
3. SELL-SIDE REVISION：距卖方预期还有多远。
4. WHY / Q2：前三个驱动和 Q2 是否加速。
5. OUTLOOK：重要利好与利空展望。
6. VALUATION：保守、基准、乐观三档目标价与空间。
7. RISKS：最多三条。

不放公司简介、大段行业背景、长 SOTP 表和估值公式。

## 迭代

新增规则时，先判断它属于：

- 数据口径：更新 `references/data-contract.md`。
- 视觉与信息层级：更新 `references/visual-template.md`。
- 错字、重复和验收：更新 `references/copy-audit.md`。
- 新场景：追加到 `evals/evals.json`。

不要把一次性公司数字写进本 Skill。
