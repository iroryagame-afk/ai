# 数据契约

## 来源优先级

1. 交易所、巨潮资讯、公司正式公告与定期报告。
2. Futu OpenD：最新价、K 线、支撑压力和成交数据；必须确认已连接。
3. 东方财富专业数据、Wind/Choice 等可识别来源：卖方一致预期、分析师数量和更新日期。
4. 券商正式研报：单家预测与目标价。
5. 权威财经媒体：仅用于补充事件背景，不替代公告。

所有“最新、当前、今日”数据都要当次核验。无法核验时写 `未核验`。

## 必备字段

| 字段 | 要求 |
| --- | --- |
| 公告口径 | 预告/快报/正式报告；报告期；发布日期 |
| 归母净利润 | 实际值或区间；同比 |
| 扣非净利润 | 实际值或区间；同比 |
| Q1 | 与 H1 使用相同口径 |
| Q2 单季 | `H1 - Q1`；区间需保留上下限 |
| Q2 环比 | `(Q2 / Q1) - 1`；不得拿累计同比替代 |
| 卖方一致预期 | 全年利润/EPS、来源、日期、分析师数 |
| 当前价格 | 数值、时间戳、盘中/收盘口径 |
| 目标价 | 保守/基准/乐观；6–12 个月 |
| 执行价格 | 当前价、直接买区/回调买区、失效线 |
| 重要展望 | 正面与负面；原文来源或推断标签 |

## 预期差计算

- H1 完成度 = H1 归母净利润 / 卖方全年归母净利润。
- 自有全年预测必须与卖方预测分栏，标注“我的测算”，不得伪装成一致预期。
- 预测上修空间 = 自有全年预测 / 当前卖方一致预期 - 1。
- 基准目标空间 = 基准目标价中枢 / 执行价格 - 1；直接买与回调买必须分别用各自执行价格计算。
- 失效成本 = 执行价格 / 失效线 - 1；显示为从执行价格到失效线的潜在跌幅。
- 若预告是区间，完成度、Q2 和上修空间也显示区间。
- 正式报告优先于预告；新公告覆盖旧公告。

## 利润质量

至少检查：

- 扣非增速是否跟随归母增速。
- 政府补助、公允价值、资产处置等非经常损益。
- 毛利率、净利率、经营现金流与应收存货变化。
- 汇兑、税率或低基数是否放大利润。

不得只凭归母同比给“利润质量高”的结论。

## 买入排序

多公司比较时，用同一报告期和同一价格时点，依次比较：

1. 基准目标空间，而不是乐观目标空间。
2. 盈利预测潜在上修幅度及证据强度。
3. 扣非利润、现金流和一次性项目反映的利润质量。
4. 从执行价格到失效线的下行成本。

当公司质量成立但当前价格空间不足时，将其归为“回调买”，不要降格成含糊的“等待”。

## 重要展望

逐项扫描并标注正负面：订单、产品价格、毛利率、产能与资本开支、客户认证、量产节奏、技术迭代、原材料、融资稀释、诉讼监管、减值和管理层指引。

来源标签只用：

- `本次公告`：公告原文直接披露。
- `公司此前披露`：来自更早公告、互动平台或业绩会，并写日期。
- `研究推断`：基于公开数据推导，不冒充公司指引。

## 产业链映射

AI 产业链公司可增加一行简短映射，但只保留与本次盈利驱动直接相关的 3–5 个节点。映射不能挤压 ACTION PLAN、卖方修正或重要展望。
