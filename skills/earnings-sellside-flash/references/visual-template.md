# 视觉模板

## 画布与气质

- 9:16 手机竖屏，建议 1080 × 1920。
- 暖白纸张底色、深海军蓝主文字、细线网格和克制留白。
- 风格是“卖方 TMT 晨会第一页 × 投资仪表盘”，不是营销海报。
- 中文标题优先使用霞鹜文楷（LXGW WenKai）；数字与英文使用清晰无衬线体。
- 全图 300–500 个中文字，最多 600 字。

## 颜色语义

- 深海军蓝：主结论、标题、卖方数据。
- 青色：已有仓位、正向事实。
- 橙色：新资金、回调区和条件触发。
- 红色：失效纪律、明确利空和风险。
- 绿色仅用于已验证的正向增量，不与青色动作栏混淆。

## 版式

### 顶部结论区

- 占约 20%–25% 高度。
- 大标题只写一次，例如“偏强超预期”。
- 下一行先写投资价值，再写执行动作，例如“值得买｜已有仓位持有｜新资金回调买”。
- 使用 3 个定性标签：`预期差 强/中/弱`、`利润质量 高/中/低`、`买入价值 高/中/低`。
- 禁止星级和 `4/5` 等无解释评分。
- “值得买”与“回调买”可以同时出现：前者评价公司，后者描述价格纪律。

### ACTION PLAN

- 放在第二视觉焦点，使用深海军蓝双边框或带轻微印章感的容器。
- ACTION PLAN 上方增加一枚投资价值章：`值得买 / 仅观察 / 不值得买`。
- 左栏青色“已有仓位”，右栏橙色“新资金”。
- 每栏只保留一个大动作词：`加仓/持有/减仓/退出`；`直接买/回调买/确认买/暂不买`。
- 大动作词可做盖章，但同一词不得在标题和印章中重复。
- 每栏最多三条条件。
- 底部红色双边框独立显示失效纪律。
- 禁止单独使用“等待”或“不追”；它们没有说明下一步动作。

### SELL-SIDE REVISION

这是全图最大的数据模块，显示：

- 当前卖方一致预期。
- 公司公告数据和全年完成度。
- 我的全年预测。
- 预计上修幅度或“暂无可靠一致预期”。
- 来源日期和分析师数量使用小字脚注。

### WHY / Q2

- 只保留前三个业绩驱动，每项一句。
- Q2 仅用 `Q1 → Q2 → 环比` 的小图，不画复杂折线。
- 明确写“真实加速”或“主要为低基数”。

### OUTLOOK

- 使用左右或上下双色块：`利好展望` 与 `利空展望`。
- 每侧最多两条，优先展示会改变盈利预测或估值的事项。
- 每条带 `本次公告/此前披露/研究推断` 标签。

### VALUATION / RISKS

- 三个色块展示保守、基准、乐观目标价和相对当前价空间。
- 风险最多三条，不重复 OUTLOOK 已写的同一句话。

### 多公司对比

- 若一次分析多家公司，正文或总览图必须增加“新资金排序”。
- 明确标出 `首选`、`次选` 和 `暂不买`，并给首选的直接买/回调买/确认买条件。
- 当日涨幅不能作为排序的唯一依据；排序优先看基准目标空间、盈利上修幅度、利润质量和失效成本。

## 确定性排版

最终中文文本优先由 HTML/SVG 排版渲染。图片生成模型只能辅助风格探索；若让模型直接写字，必须逐字核对后再交付。

参考图 `../assets/layout-reference.svg` 只用于学习层级、边框、留白和字体气质，不复制公司数据。
