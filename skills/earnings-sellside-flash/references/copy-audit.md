# 全图文案审计

## 逐字核对

将最终图片中的文字与定稿文案逐项对照：公司名、证券代码、币种、单位、日期、利润口径、价格、百分比和箭头方向。

图片生成模型产出的文字不能凭肉眼扫一遍就通过；需逐区抄录或 OCR 后对照。

## 重复检查

用“语义”而不只是完全相同字符串查重：

- `持仓持有` 与 `继续持有` 属于重复。
- `新仓不追` 与 `新资金等待机会` 若无新增条件，属于重复。
- 单独出现“等待”或“不追”属于不完整指令，即使没有重复也不能通过。
- 顶部结论与 ACTION PLAN 可以互相指引，但不能逐句复述。
- 风险与利空展望只有在一个讲事件、一个讲失效后果时才可同时出现。
- 同一数字若因不同公式必须出现两次，第二处要标明新含义。

发现重复时，保留更具体、可执行、离决策更近的一处。

## 口径冲突检查

- 归母不得和扣非直接相减或互换。
- 累计同比不得写成最新单季同比。
- 卖方一致预期、单家券商预测和“我的预测”必须分开。
- 当前价与目标价必须使用同一复权/币种口径。
- 上涨空间的正负号、分母和取整必须一致。

## 视觉检查

- 一眼先看到结论和 ACTION PLAN。
- 已有仓位与新资金不会看串。
- 投资价值章和执行动作含义不同，例如“值得买｜回调买”，不会互相替代。
- 操作大字只有一个，不出现“持有持有”。
- 失效纪律有红色双边框或清晰印章感。
- 手机宽度下最小字仍可读。
- 无裁切、溢出、乱码、伪字和残留旧版本元素。
